# 지도

1. 진입 시 데이터가 로드 되는 동안 스켈레톤 UI를 보여준다
   - 진입 시 현재 위치로 이동하는 동안과 이동한 위치의 공연장 목록을 불러오는 동안에도 스켈레톤 UI를 보여준다
   - 지도를 불러오지 못하면 지도 자리에 “지도를 불러오지 못했습니다. 잠시 후 다시 시도해 주세요.”를 보여준다
2. 공통 UI 하단 나브 참조
3. 위치 권한이 정해지지 않았다면 진입 시 위치 정보 서비스 동의를 얻는 모달을 띄운다
   - 공통 UI 모달 참조
   - 제목 “위치 정보 서비스 동의”
   - 내용 “위치 정보 사용에 동의가 필요한 서비스 입니다. 동의 하시겠습니까?”
   - 동의하기 버튼을 누르면 현재 위치로 지도를 이동한다
   - 취소하기 및 모달 외의 영역을 눌러 모달을 닫을 수 있으며, 이 경우 기본 위치의 지도를 보여준다
   - 위치 권한이 이미 허용 돼 있으면 모달 없이 현재 위치로 이동하고, 이미 거부 돼 있으면 모달 없이 기본 위치를 보여준다
   - 공연 상세에서 공연장 위치로 넘어온 경우(url(”/map?lat={공연장 위도}&lng={공연장 경도}”))에는 모달을 띄우지 않는다
4. 상단 검색창을 통해 공연장·공연·지역을 검색할 수 있다
   - placeholder “원하시는 지역을 검색해 보세요”
   - 검색창에 포커스가 들어가면 강조 UI가 들어간다
   - 돋보기 버튼을 누르거나 enter을 누르면 api 요청을 보낸다
   - api 요청을 보내는 동안 스켈레톤 UI를 보여준다
   - 검색어가 지역이면 지도를 그 지역으로 이동한다
   - 검색어가 공연장·공연이면 현재 지도 중심에서 가장 가까운 공연장으로 이동하고 그 공연장을 바텀 시트에 보여준다
   - 검색 결과가 없거나 검색이 실패하면 상단에 “검색 결과를 찾을 수 없습니다”라는 문구와 함께 토스트를 보여준다
5. 지도 영역을 통해 공연장의 위치를 사용자는 확인할 수 있다
   - 공연장의 위치를 마크 UI로 확인할 수 있다
   - 사용자는 자신의 위치를 확인할 수 있다
   - 마커를 클릭하면 마커가 약간 커지며 마커 위에 공연장의 이름이 말풍선 형태로 나타난다
   - 마커를 클릭하면 해당 공연장의 공연 목록이 바텀 시트에 나타난다
   - 지도를 끌어 지도 위치를 변경할 수 있다
   - 지도를 줌 인 줌 아웃을 할 수 있다
6. 현재 위치 버튼을 눌러 현재 위치로 지도를 이동할 수 있다
   - 위치 권한이 막혀 현재 위치를 가져오지 못하면 지도는 그대로 두고 안내 모달을 띄운다
   - 안내 모달 제목 “위치 정보 서비스 동의”
   - 안내 모달 내용 “위치 정보 접근 권한이 허용되어 있지 않습니다. 서비스 이용을 위해 위치 정보 사용을 허용 하시고 다시 시도해 주세요.”
   - 안내 모달은 X 아이콘으로 닫는다
   - 안내 모달이 떠 있는 동안 브라우저 설정에서 위치를 허용하면 모달을 닫고 현재 위치로 이동한다
7. 공연장 공연 정보 바텀 시트
   - 바텀 시트는 항상 화면에 떠 있으며, 지도 범위에서 가장 가까운 공연장을 보여준다
   - 처음 진입할 때, 현재 위치로 이동했을 때 그 범위에서 가장 가까운 공연장으로 바뀐다. 마커를 클릭하거나 검색하면 그 공연장으로 바뀐다
   - 지도를 끌어 옮기기만 하면 보여주던 공연장을 그대로 유지한다
   - 이동한 범위에 공연장이 없다면 “공연장을 선택해 주세요”라는 문구를 보여준다
   - 핸들러를 위로 끌면 최대 높이로, 아래로 끌면 기본 높이로 바뀐다. 키보드로도 조작할 수 있다
   - 공연장 이름을 사용자는 읽을 수 있다
   - 공연장의 공연 개수를 사용자는 알 수 있다 (“{공연장 이름} · 공연 {개수}개”)
   - 공연장의 공연 항목을 통해 공연 포스터, 공연 이름, 공연 기간, 하트 버튼을 콘텐츠로 제공한다
   - 공연장에 공연이 없다면 공연 목록 자리에 “오늘은 공연이 없습니다”라는 문구를 보여준다
   - 공통 UI 하트 버튼 참조
   - 비로그인 상태에서 하트 버튼을 누르면 로그인 유도 모달이 나온다(디테일 페이지-비 로그인 참조)
   - 공연장의 공연 항목을 눌러 url(”/detail/:id”)로 넘어간다
