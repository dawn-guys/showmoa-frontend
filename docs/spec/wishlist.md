# 찜-비 로그인

1. 공통 UI 헤더-비 로그인 참조
2. 로그인 하러 가기 버튼을 눌러 url(”/login”)으로 이동한다
3. 로그인이 필요한 서비스 페이지인 걸 사용자에게 알리는 문구인 “로그인이 필요한 서비스 입니다”를 알려준다
4. 아직 회원가입을 안 한 사용자일 경우 “아직 회원이 아니신가요?”라는 문구와 함께 회원가입 페이지로 넘어갈 수 있는 링크를 제공한다
5. 회원가입 링크를 눌러 url(”/signup”)으로 넘어간다

# 찜-로그인

1. 진입 시 데이터가 로드 되는 동안 스켈레톤 UI를 보여준다
2. 공통 UI 헤더-로그인 참조
3. 해당 페이지의 제목을 사용자는 알 수 있다
4. 현재 필터링 상태를 텍스트로 사용자는 알 수 있다
5. 햄버거 아이콘을 눌러 사용자는 바텀 시트를 꺼낼 수 있다
   - 바텀 시트 외부 영역을 눌러 바텀 시트를 닫을 수 있다
   - 바텀 시트 X 버튼을 눌러 바텀 시트를 닫을 수 있다
   - 바텀 시트의 필터링 목록을 선택할 수 있다
   - 바텀 시트의 필터링 목록은 공통 UI 장르 카테고리 참조 (전체 포함)
   - 필터링 항목을 선택하지 않으면 바텀 시트의 CTA 버튼이 비활성화 된다
   - 필터링 항목을 선택하면 주조색으로 강조하고 CTA 버튼이 활성화 된다
6. 검색창을 통해 공연의 제목을 검색할 수 있다
   - 검색창에 포커스가 들어가면 테두리를 주조색으로 강조한다
   - 돋보기 아이콘을 누르거나 enter 키를 누르면 검색을 하여 찜 한 공연 목록을 필터링 한다
7. 찜 한 공연 목록을 사용자에게 보여줄 수 있다
   - 목록 항을 통해 공연 포스터, 공연 제목, 공연 상태, 하트 버튼을 사용자에게 제공한다
   - 찜 한 공연 목록 항을 눌러 url(”/detail/:id”)으로 넘어간다
   - 하트 버튼을 눌러 공연을 찜 한 공연 목록에서 지울 수 있다
   - 공연 종료의 목록의 항은 디세이블 된 상태로 표시 되며 url(”/detail/:id”)로 넘어가지 않는다
   - 공연 종료 된 목록의 항은 하트 버튼을 통해 찜 목록에서 지울 수 있다
   - 하트 버튼을 눌러 찜을 지우는 데 실패하면 에러 토스트를 보여준다-공통 UI 하트 버튼 참조
8. 찜 한 공연 목록을 불러오지 못하면 목록 자리에 “좋아요 한 공연을 불러오지 못했습니다. 잠시 후 다시 시도해 주세요”를 보여준다
