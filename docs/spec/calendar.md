# 캘린더-비 로그인

1. 공통 UI 헤더-비 로그인 참조
2. 로그인 하러 가기 버튼을 눌러 url(”/login”)으로 이동한다
3. 로그인이 필요한 서비스 페이지인 걸 사용자에게 알리는 문구인 “로그인이 필요한 서비스 입니다”를 알려준다
4. 아직 회원가입을 안 한 사용자일 경우 “아직 회원이 아니신가요?”라는 문구와 함께 회원가입 페이지로 넘어갈 수 있는 링크를 제공한다
5. 회원가입 링크를 눌러 url(”/signup”)으로 넘어간다

# 캘린더-로그인

1. 진입 시 데이터가 로드 되는 동안 스켈레톤 UI를 보여준다
2. 공통 UI 헤더-로그인 참조
3. 사용자에게 선택한 날짜의 요일, 월, 일을 알 수 있게 제공 한다
   - “{요일}, {M}월 {D}일” 형식으로 보여준다 (예: 수요일, 9월 23일). 처음에는 오늘이고, 월간 달력에서 날짜를 누르거나 주간 달력에서 요일을 고르면 그 날짜로 바뀐다
   - 해당 text를 눌러 월을 선택할 수 있는 휠 피커를 꺼낼 수 있다
   - 당월의 휠 섹션이 선택 영역으로 잡힌다 (3월이면 3월부터 강조 된다, 만약 선택 값이 있다면 선택 값이 선택 영역으로 시작 한다)
   - 휠을 내려거나 스와이프를 통해 해당 휠 피커의 값을 선택할 수 있다
   - x아이콘을 누르거나 휠 피커 시트 외의 백그라운드 레이아웃 영역을 클릭하면 휠피커 시트를 닫을 수 있다
   - 값을 1월~12월이다. 연도는 올해로 고정한다
   - 값을 선택하고 CTA 버튼을 누르면 선택한 달의 달력 UI를 보여준다.
   - CTA 버튼 문구 “완료”
4. 텍스트 토글 버튼을 눌러 달력 UI를 월간/주간으로 변경할 수 있다
   - 월간 달력에서는 “주간”, 주간 달력에서는 “월간”을 보여준다
5. 찜 한 공연은 공연 기간 안에서 실제로 공연하는 날에만 표시한다
   - 공연하는 요일에 표시한다
   - 공휴일에도 공연하는 공연은 공휴일에도 표시한다
   - 공연하는 요일 정보가 없는 공연은 공연 기간 전체에 표시한다
   - 공휴일 정보를 불러오지 못하면 공휴일 표시만 빼고 요일 기준으로 표시한다
6. 월간 달력 UI
   - 월화수목금토일 각 요일별로 달력 카드를 볼 수 있다
   - 다른 달의 날짜는 흐리게 표시하며 누를 수 없다
   - 달력 카드 안에 공연 제목을 목록으로 읽을 수 있다
   - 공연 제목 목록 항에 그 공연의 고유 색상을 통해 공연을 시각적으로 분류할 수 있다. 같은 공연은 달과 보기 방식이 바뀌어도 같은 색상이다
   - 제목이 카드 UI의 넓이를 벗어나면 …을 사용해 공연 제목을 가린다
   - 선택한 날짜(처음에는 오늘)의 숫자에 주조색으로 강조 한다
   - 달력 카드를 눌러 그 카드가 속 한 날의 공연 리스트를 담은 바텀 시트를 꺼낼 수 있다
   - 바텀 시트 제목으로 사용자가 선택한 날을 알린다 (“{M}월 {D}일 일정”)
   - 바텀 시트의 제목 옆의 화살표 아이콘을 눌러 바텀 시트를 내릴( 닫을 ) 수 있다
   - 바텀 시트에서 공연 목록을 사용자에게 제공한다
   - 바텀 시트의 공연 목록 항을 통해 사용자에게 공연 포스터, 공연 제목, 공연 위치, 공연 기간, 하트 버튼을 제공한다
   - 공연 기간은 “yyyy.MM.dd - yyyy.MM.dd”로 보여주며, 하루만 공연하면 날짜 하나만 보여준다. 끝나는 날이 없는 공연은 끝나는 기간을 “종료 기간 미정”으로 표시한다
   - 그 날 공연이 없다면 “이 날은 공연이 없습니다”라는 문구를 보여준다
   - 바텀 시트의 공연 목록 항을 눌러 url(”/detail/:id”)로 넘어간다
   - 공통 UI 하트 버튼 참조
   - 찜 목록에 들어가 있는 하트를 지울 경우 찜 목록에서 제외 돼서 캘린더에서도 제외 된다
   - 달력 UI가 화면을 넘어 갈 경우 스크롤 가능하게 만든다 다만 스크롤 UI는 숨긴다 
7. 주간 달력 UI
   - 금주(월요일~일요일)를 보여준다
   - 선택한 요일의 공연 목록을 사용자에게 제공한다
   - 공연 목록 항을 통해 사용자에게 공연 포스터, 공연 제목, 공연 위치, 공연 기간, 하트 버튼을 제공한다
   - 선택한 요일에 공연이 없다면 “이 날은 공연이 없습니다”라는 문구를 보여준다
   - 공연 목록 항을 눌러 url(”/detail/:id”)로 넘어간다
   - 공통 UI 하트 버튼 참조
8. 찜 한 공연 일정을 불러오지 못하면 달력 자리에 “공연 일정을 불러오지 못했습니다. 잠시 후 다시 시도해 주세요”를 보여준다
