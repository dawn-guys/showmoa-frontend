# 검색

1. 로그인 상태에 따라 헤더가 달라진다(공통 UI 헤더 - 비 로그인, 로그인 참조)
2. 공통 UI 하단 나브 참조
3. 검색창을 통해 공연을 검색할 수 있다
   - 검색창에 포커스가 들어가며 검색창이 상단에 올라간다
   - 검색창에 포커스가 들어가면 테두리에 주조색으로 강조한다
   - 화살표 버튼을 눌러 검색창 포커스 전의 공연 페이지 UI로 돌아간다
   - 필터링이 걸려 있다면 검색창 하단에 필터링 된 정보를 칩 UI로 제공한다
   - 검색 된 공연 목록을 사용자에게 보여줄 수 있다
   - 검색 된 공연 목록의 항에서는 공연 포스터, 공연 제목, 공연 장르를 제공한다
   - 검색 된 공연 목록의 항을 눌러 url(”/detail/:id”)로 넘어간다
4. 검색 필터링을 통해 장르와 지역을 필터링 할 수 있다
   - 장르 필터 버튼을 눌러 장르 필터 바텀 시트를 꺼낼 수 있다
   - 장르 필터 바텀 시트 외의 영역을 눌러 바텀 시트를 닫을 수 있다
   - 장르 필터 바텀 시트의 X 아이콘을 눌러 바텀 시트를 닫을 수 있다
   - 장르 필터에서 장르 목록은 공통 UI 장르 카테고리 참조 (전체 포함)
   - 항목을 선택하지 않으면 CTA 버튼이 비활성화 된다
   - 선택 된 목록 항목으로 주조색으로 강조 한다
   - 항목을 선택 했다면 CTA 버튼이 활성화 되며 사용자가 검색창을 통해 검색할 경우 칩 UI를 통해 사용자에게 선택 된 필터링 정보를 제공한다
   - 지역 필터 버튼을 눌러 지역 필터 드로워를 나타나게 한다
   - 공통 UI 지역 필터 드로워 참조
