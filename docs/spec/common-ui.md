# 공통 UI

## 헤더-비 로그인 상태

1. 로고를 누르면 url(”/”)로 이동한다
2. 톱니바퀴 아이콘을 누르면 url(”/setting”)으로 이동한다

## 헤더-로그인 상태

1. 로고를 누르면 url(”/”)로 이동한다
2. 종 아이콘을 누르면 url(”/notification”)로 이동한다
3. 톱니바퀴 아이콘을 누르면 url(”/setting”)으로 이동한다

## 타이머

1. 사용자는 요청의 남은 시간을 볼 수 있다.
2. 사용자의 요청의 재요청을 눌러 시간을 초기화 할 수 있다
3. 재요청에 커서를 올릴 경우 #f6f6f6으로 색상이 변경 된다

## 인풋

1. 인풋에 포커스가 들어가면 주조색이 테두리에 표현 된다
2. 인풋에 블러가 생기면 주조색이 빠진다
3. 해당 동작이 들어가는 요청에 에러가 생길 경우 테두리에 에러 색상이 표현 되며 상단에 에러 토스트를 보여준다
4. 비밀번호 인풋일 경우 눈 모양 아이콘을 눌러 비밀번호를 볼 수 있다
5. 비밀번호 인풋의 눈 모양 아이콘이 활성화 돼 있을 경우 눈 닫기 아이콘을 눌러 비밀번호를 암호화 할 수 있다

## 로딩 스피너

1. 특정 ui에서 로딩이 일어날 경우 피그마 디자인 시스템 내의 로딩 스피너가 애니메이션과 함께 동작한다

## 공통 모달

1. 모달의 제목을 사용자는 읽을 수 있다
2. 모달의 주 목적을 사용자는 읽을 수 있다
3. 모달 취소 버튼을 눌러 사용자는 모달을 닫고 주 목적을 취소 할 수 있다
4. 모달의 주 목적이 담긴 버튼을 눌러 주 목적의 동작을 일으킨다.
5. 모달에는 백 그라운드 레이아웃이 깔린다
6. 백 그라운드 레이아웃을 누르면 모달을 닫을 수 있다

## 하단 나브

1. 이동한 url에 맞춰 아이콘의 색상이 변경 된다
2. 홈 아이콘을 누르면 url(”/”)로 이동한다 (로그인 여부와 무관하게 동일 경로, 컴포넌트 레벨에서 분기)
3. 맵 아이콘을 누르면 url(”/map”)으로 이동한다
4. 달력 아이콘을 누르면 url(”/calendar”)으로 이동한다
5. 하트 아이콘을 누르면 url(”/wishlist”)로 이동한다
6. 돋보기 아이콘을 누르면 url(”/search”)로 이동한다

## 지역 필터 드로워

1. 공용 UI 앱바 참조
2. 사용자는 본인이 선택한 위치를 읽을 수 있으면 지역을 선택하지 않았을 경우 “필터링 할 지역을 선택해 주세요” 라는 문구를 읽을 수 있다
3. 리스트를 위 아래로 부드럽게 스크롤 할 수 있다
4. 지역은 시/도 → 구/군 두 단계로 선택한다. 지역 목록은 실제 공연이 있는 지역만 보여준다
   - 동 단계는 지역 데이터에 없어 제공하지 않는다
5. 사용자는 시/도 리스트에서 시/도를 하나 선택할 수 있다
   - 시/도 표기는 검색 문서의 지역 드로워 값을 따르며, 표기가 없는 지역(해외 등)은 보여주지 않는다
   - 다른 시/도를 선택하면 이전에 선택한 구/군은 해제된다
6. 사용자가 시/도를 선택 했다면 구/군을 최대 3개까지 선택할 수 있다
   - 3개를 선택하면 나머지 구/군은 선택할 수 없게 비활성화 된다
   - 선택한 구/군을 다시 누르면 선택이 해제된다
7. 시/도 리스트 맨 위의 “전체”를 누르면 선택을 비우고 적용된 지역 필터도 바로 해제한다
8. 구/군을 하나 이상 선택 했다면 하단에서 CTA 버튼이 생기고 해당 버튼을 눌러 지역 필터링을 걸 수 있다
   - CTA 버튼 문구 “저장”
   - 저장하지 않고 드로워를 닫으면 바꾼 선택은 반영되지 않는다

## 장르 카테고리

1. 서비스 전역(홈 카테고리 탭, 검색 장르 필터, 찜 필터링)에서 사용하는 공연 장르 카테고리는 연극, 뮤지컬, 콘서트, 클래식, 기타 5개이다
   - KOPIS Open API 세부 장르(`genrenm`)를 5개 서비스 카테고리로 통합한 것이다: 연극(연극), 뮤지컬(뮤지컬), 콘서트(대중음악), 클래식(서양음악·한국음악), 기타(무용, 대중무용, 서커스/마술, 복합)
2. 모든 카테고리/필터 UI(홈 카테고리 탭, 검색 장르 필터, 찜 필터링)에는 위 5개 카테고리 앞에 “전체” 옵션이 노출되며, “전체” 선택 시 장르로 필터링 되지 않은 전체 공연 데이터를 보여준다

## 공연 리스트

1. 리스트를 눌러 url(”/detail/:id”)로 이동한다
2. 하트를 눌러 좋아요를 추가 혹은 취소를 할 수 있다

## 토스트

1. 특정 동작의 에러 및 결과를 사용자에게 보여준다

## CTA 버튼

1. 비활성화 된 버튼은 동작하지 않는다
2. 활성화 된 버튼을 눌러 동작을 일으킬 수 있다
3. API 요청 시 버튼에 로딩 애니메이션이 동작한다

## 앱바

1. 화살표 아이콘을 눌러 url 뒤로 가기 혹은 드로워를 끌 수 있다
2. 해당 콘텐츠의 제목을 사용자가 읽을 수 있다

## 카드

1. 카드를 눌러 url(”/detail/:id”)로 이동할 수 있다

## 하트 버튼

1. 하트 버튼을 누르면 화면에 애니메이션 효과와 함께 하트 아이콘이 생기며 사라진다
2. 하트 버튼을 눌러 해당 공연을 좋아요 목록에 넣을 수 있다
3. 하트 버튼 UI를 통해 좋아요의 상태를 사용자는 알 수 있다
4. 좋아요 추가·취소 요청이 실패하면 에러 토스트에 “좋아요를 반영하지 못했습니다. 잠시 후 다시 시도해 주세요”를 보여준다

## 푸터

1. 개인 정보 처리 방침을 눌러 개인정보처리방침을 읽을 수 있다
2. 위치 정보 서비스 이용 약관을 눌러 위치 정보 서비스 이용 약관을 읽을 수 있다.
3. 팀원들 이름 리스트를 눌러 팀원의 개인 깃허브 주소로 이동 한다
4. 프로젝트 주소를 눌러 show moa 프로젝트 오가니제이션 주소로 이동 한다

## 에러 페이지(404)

1. 상단 화살표 아이콘을 눌러 이전 페이지로 넘어간다
2. 메인 문구 ”이 공연은 막을 내렸어요”
3. 서브 문구 “찾으시는 페이지를 무대에서 찾을 수 없네요<br/>대신 지금 열리고 있는 공연을 보러 가실래요?
4. 공통 UI CTA버튼
   - CTA 버튼 문구 “홈으로”
   - CTA 버튼을 눌러 url(”/”)로 이동할 수 있다
5. 없는 주소로 들어오거나, 이메일 인증 타이머가 만료 되거나, 공연 상세 조회에 실패하면 이 페이지를 보여준다
   - 회원가입·비밀번호 찾기·비밀번호 변경 중 타이머 만료로 넘어온 경우 상단 화살표는 해당 화면의 첫 단계로 돌아간다
