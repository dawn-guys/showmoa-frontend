# 디테일 페이지-공통

1. 사용자는 공연의 제목을 읽을 수 있다
2. 사용자는 공연장 위치를 알 수 있다
3. 사용자는 공연의 장르와 공연 상태를 알 수 있다
4. 사용자는 share 아이콘을 눌러 해당 디테일 페이지의 url을 복사할 수 있다
   - 복사에 성공하면 상단에 성공 토스트에 “주소를 복사 했습니다”를 보여준다
5. 사용자는 공연의 포스터를 볼 수 있다
6. 사용자는 상세 보기 버튼을 눌러 공연의 상세 정보가 담긴 이미지들을 볼 수 있다
7. 공연 정보를 알 수 있다
   - 제목 “공연 정보”
   - 공연의 시작 기간과 끝나는 기간을 알 수 있다
   - 만약 공연이 오픈런인 경우 끝나는 기간은 제공하지 않는다
   - 공연의 시작 시간과 끝나는 시간을 알 수 있다
   - 공연의 나이 제한을 알 수 있다
   - 공연의 예매처를 버튼으로 제공하면 클릭하면 해당 공연의 예매처로 이동한다
8. 사용자는 출연진을 알 수 있다
   - 제목 “출연진”
   - 공연의 출연진을 알 수 있다
9. 공연장 주소와 공연장의 전화 번호를 알 수 있다
   - 제목 “공연장 주소”
   - 제목 옆 화살표 아이콘을 눌러 해당 공연장의 위치를 보여주는 지도로 이동한다 url(”/map?search={공연장 주소}”)
   - 공연장의 위치를 지도로 간략하게 보여준다
   - 공연장의 주소를 도로명 주소로 보여주며 주소 옆 아이콘을 눌러 텍스트를 복사한다. 해당 텍스트를 복사하면 상단에 토스트를 보여주며 “공연장의 주소를 복사 했습니다”를 보여준다
   - 공연장의 주소를 지번 주소로 보여주며 주소 옆 아이콘을 눌러 텍스트를 복사한다. 해당 텍스트를 복사하면 상단에 토스트를 보여주며 “공연장의 주소를 복사 했습니다”를 보여준다
   - 공연장의 건물명을 사용자에게 보여준다
   - 공연장의 전화번호를 알 수 있다
10. 하단 버튼들
   - skip 아이콘이 담긴 버튼을 눌러 이전 페이지로 이동한다
   - 좋아요 버튼-공통 UI CTA 버튼 참조
   - 좋아요 CTA 버튼을 눌러 해당 공연을 찜 할 수 있다
   - 좋아요 버튼을 누르면 하트 애니메이션을 보여준다
   - 좋아요 요청을 보내고 실패하면 에러 토스트에 “네트워크 문제가 생겼습니다. 다시 시도해 주세요”를 보여준다
11. 진입 시 데이터가 로드 되는 동안 스켈레톤 UI를 보여준다

# 디테일 페이지-비 로그인

1. 공통 UI 헤더-비로그인 참조
2. 하단 좋아요 CTA 버튼을 누르면 로그인 유도 모달이 나온다
   - 공통 UI 모달 참조
   - 제목 “로그인”
   - 내용 “로그인이 필요한 서비스 입니다. 로그인 하시겠습니까?”
   - 로그인 하기 버튼을 클릭하면 url(”/login”)으로 넘어간다
   - 취소하기 및 모달 외의 영역을 눌러 모달을 닫을 수 있다
