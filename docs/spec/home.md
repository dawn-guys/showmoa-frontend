# 홈-공통

1. 진입 시 데이터가 로드 되는 동안 스켈레톤 UI를 보여준다
2. 스플래쉬 애니메이션이 동작하며 진입 한다
   - 스플래쉬 애니메이션은 브라우저 탭에서 처음 열 때 1회만 보여준다. 같은 탭에서는 홈에 다시 들어오거나 새로고침해도 보여주지 않는다
   - 로그인 여부와 무관하게 동일하다
3. 섹션 데이터를 불러오지 못하면 지어낸 안내 문구 없이 해당 섹션의 목록 자리를 비운다

# 홈-비 로그인

1. 공통 UI 헤더-비로그인 참조
2. 공통 UI 하단 나브 참조
3. 주목 받는 공연의 제목과 포스터 이미지를 클릭하면 url(”/detail/:id”)로 넘어간다
   - 공연 제목, 공연장 위치, 공연 장르, 공연 포스터
   - 종료되지 않은 공연 중 1개를 무작위로 보여준다
   - 보여줄 공연이 없거나 불러오지 못하면 섹션을 보여주지 않는다
4. 인기 있는 공연 순위를 리스트로 사용자에게 보여준다
   - 제목 “인기 있는 공연 순위”
   - 리스트의 행을 클릭하면 url(”/detail/:id”)로 넘어간다
   - 공연 순위, 공연 제목, 공연 포스터 이미지
   - 찜이 많은 순으로 상위 5개를 보여주며, 종료된 공연은 제외한다
   - 순위에 올릴 공연이 없거나 불러오지 못하면 섹션을 보여주지 않는다
5. 카테고리 별 공연을 사용자에게 보여준다
   - 제목 “공연 카테고리”
   - 카드를 클릭하면 url(”/detail/:id”)로 넘어간다
   - 카테고리를 눌러 카드 리스트를 필터링 할 수 있다
   - 공통 UI 장르 카테고리 참조
   - 리스트를 슬라이딩 해서 목록을 볼 수 있다
   - 카드 하단에 공연 상태를 보여준다: 공연 중이면 “공연 중”, 예정이면 “{M}월 {D}일 오픈”, 종료면 “공연 종료”
   - 해당 카테고리에 공연이 없다면 “해당 카테고리의 공연이 없습니다”라는 문구를 사용자에게 보여준다
6. 공통 UI 푸터 참조

# 홈-로그인

1. 공통 UI 헤더-로그인 참조
2. 공통 UI 하단 나브 참조
3. 주목 받는 공연, 인기 있는 공연 순위, 카테고리 별 공연은 홈-비 로그인과 같다
4. 좋아요 한 공연을 사용자에게 보여준다
   - 제목 “내가 좋아요한 공연”
   - 카드를 클릭하면 url(”/detail/:id”)로 넘어간다
   - 리스트를 슬라이딩 해서 목록을 볼 수 있다
   - 제목 옆 아이콘을 눌러 url(”/wishlist”)로 넘어간다
   - 카드에 공연 장르와 진행 상태를 보여준다: 공연 중이면 “진행 중”, 예정이면 “D-{남은 일수}”, 종료면 “공연 종료”
   - 콘텐츠가 없다면 “좋아요 한 공연이 없습니다”라는 문구를 사용자에게 보여준다
5. 캘린더에 저장한 오늘의 공연들을 사용자에게 보여준다
   - 제목 “오늘 나의 공연”
   - 캘린더와 같은 기준으로 오늘 실제로 공연하는 공연만 보여준다(캘린더-로그인 참조)
   - 카드를 클릭하면 url(”/detail/:id”)로 넘어간다
   - 리스트를 슬라이딩 해서 목록을 볼 수 있다
   - 제목 옆 아이콘을 눌러 url(”/calendar”)로 넘어간다
   - 콘텐츠가 없다면 “오늘 공연 일정이 없습니다”라는 문구를 사용자에게 보여준다
6. 공통 UI 푸터 참조
