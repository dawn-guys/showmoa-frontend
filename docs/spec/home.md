# 홈-공통

1. 진입 시 데이터가 로드 되는 동안 스켈레톤 UI를 보여준다

# 홈-비 로그인

1. 스플래쉬 애니메이션이 동작하며 진입 한다
   - 스플래쉬 애니메이션은 하루 최초 1회 진입 시에만 보여줌
2. 공통 UI 헤더-비로그인 참조
3. 공통 UI 하단 나브 참조
4. 주목 받는 공연의 제목과 포스터 이미지를 클릭하면 url(”/detail/:id”)로 넘어간다
   - 공연 제목, 공연장 위치, 공연 장르, 공연 포스터
5. 인기 있는 공연 순위를 리스트로 사용자에게 보여준다
   - 리스트의 행을 클릭하면 url(”/detail/:id”)로 넘어간다
   - 공연 순위, 공연 제목, 공연 포스터 이미지
6. 카테고리 별 공연을 사용자에게 보여준다
   - 카드를 클릭하면 url(”/detail/:id”)로 넘어간다
   - 카테고리를 눌러 카드 리스트를 필터링 할 수 있다
   - 공통 UI 장르 카테고리 참조
7. 공통 UI 푸터 참조

# 홈-로그인

1. 공통 UI 헤더-로그인 참조
2. 공통 UI 하단 나브 참조
3. 주목 받는 공연의 제목과 포스터 이미지를 클릭하면 url(”/detail/:id”)로 넘어간다
   - 공연 제목, 공연장 위치, 공연 장르, 공연 포스터
4. 인기 있는 공연 순위를 리스트로 사용자에게 보여준다
   - 리스트의 행을 클릭하면 url(”/detail/:id”)로 넘어간다
   - 공연 순위, 공연 제목, 공연 포스터 이미지
5. 카테고리 별 공연을 사용자에게 보여준다
   - 카드를 클릭하면 url(”/detail/:id”)로 넘어간다
   - 카테고리를 눌러 카드 목록을 필터링 할 수 있다
   - 공통 UI 장르 카테고리 참조
   - 리스트를 슬라이딩 해서 목록을 볼 수 있다
6. 좋아요 한 공연을 사용자에게 보여준다
   - 카드를 클릭하면 url(”/detail/:id”)로 넘어간다
   - 리스트를 슬라이딩 해서 목록을 볼 수 있다
   - 제목 옆 아이콘을 눌러 url(”/wishlist”)로 넘어간다
   - 콘텐츠가 없다면 “좋아요 한 공연이 없습니다”라는 문구를 사용자에게 보여준다
7. 캘린더에 저장한 오늘의 공연들을 사용자에게 보여준다
   - 카드를 클릭하면 url(”/detail/:id”)로 넘어간다
   - 리스트를 슬라이딩 해서 목록을 볼 수 있다
   - 제목 옆 아이콘을 눌러 url(”/calendar”)로 넘어간다
   - 콘텐츠가 없다면 “오늘 공연 일정이 없습니다”라는 문구를 사용자에게 보여준다
8. 공통 UI 푸터 참조
