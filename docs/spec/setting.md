# 설정-공통

1. 공통 UI 앱바 참조
2. 운영 정책
3. 개인 정보 처리 방침을 눌러 개인 정보 처리 방침 드로워를 애니메이션과 함께 나타나게 한다
   - 개인 정보 처리 방침 드로워 공통 UI 앱바 참조
   - 사용자는 개인 정보 처리 방침을 스크롤을 하며 읽을 수 있다
4. 위치 정보 서비스 이용 약관을 눌러 위치 정보 서비스 이용 약관 드로워를 애니메이션과 함께 나타나게 한다
   - 위치 정보 서비스 이용 약관 드로워 공통 UI 앱바 참조
   - 위치 정보 서비스 이용 약관을 스크롤을 하며 읽을 수 있다

# 설정-비 로그인

1. 사용자는 로그인을 눌러 url(”/login”)으로 넘어갈 수 있다
2. 사용자는 회원가입을 눌러 url(”/signup”)으로 넘어갈 수 있다

# 설정-로그인

1. 사용자는 로그인 한 본인의 계정을 알 수 있다
2. 비밀번호 변경을 눌러 url(”/password/update”)로 넘어간다
3. 로그 아웃 버튼을 눌러 로그 아웃 모달을 화면에 띄운다
4. 공통 UI 모달 참조
