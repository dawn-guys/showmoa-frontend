# 설정-공통

1. 공통 UI 앱바 참조
2. 운영 정책
3. 개인 정보 처리 방침을 눌러 개인 정보 처리 방침 드로워를 애니메이션과 함께 나타나게 한다
   - 개인 정보 처리 방침 드로워 공통 UI 앱바 참조
   - 사용자는 개인 정보 처리 방침을 스크롤을 하며 읽을 수 있다
4. 위치 정보 서비스 이용 약관을 눌러 위치 정보 서비스 이용 약관 드로워를 애니메이션과 함께 나타나게 한다
   - 위치 정보 서비스 이용 약관 드로워 공통 UI 앱바 참조
   - 위치 정보 서비스 이용 약관을 스크롤을 하며 읽을 수 있다

# 설정-비 로그인

1. 사용자는 로그인을 눌러 url(”/login”)으로 넘어갈 수 있다
2. 사용자는 회원가입을 눌러 url(”/signup”)으로 넘어갈 수 있다

# 설정-로그인

1. 사용자는 로그인 한 본인의 계정(이메일)을 알 수 있다
2. 비밀번호 변경을 눌러 url(”/password/update”)로 넘어간다
   - 소셜 계정(구글·카카오)은 비밀번호가 없어 비밀번호 변경이 보이지 않는다
3. 회원 탈퇴를 눌러 url(”/setting/withdraw”)로 넘어간다
4. 로그 아웃 버튼을 눌러 로그 아웃 모달을 화면에 띄운다
   - 공통 UI 모달 참조
   - 제목 “로그 아웃”
   - 내용 “로그 아웃을 하면 특정 서비스를 사용하실 수 없습니다. 로그아웃 하시겠습니까?”
   - 로그아웃 버튼을 누르면 로그아웃 되고 url(”/”)로 넘어간다. 로그아웃 요청이 실패해도 로그아웃 상태로 url(”/”)로 넘어간다

# 회원 탈퇴-공통

1. 공통 UI 앱바 참조
   - 제목 “회원 탈퇴”
2. 로그인이 필요한 화면이다
3. 일반 계정은 비밀번호로, 소셜 계정(구글·카카오)은 이메일 인증으로 본인을 확인한다
4. 본인 확인 후 탈퇴 확인 모달을 띄우며, 모달에서 확정해야 탈퇴 된다
   - 공통 UI 모달 참조
   - 제목 “회원 탈퇴”
   - 내용 “탈퇴 시 계정 정보 및 서비스 이용 기록이 모두 삭제되며 복구할 수 없습니다. 소셜 로그인의 경우 연동이 해제됩니다.”
   - 확인 버튼 문구 “회원 탈퇴”
5. 탈퇴가 완료 되면 로그아웃 되고 url(”/”)로 넘어간다

# 회원 탈퇴-일반 계정

1. 비밀번호 인풋을 작성할 수 있다
   - 공통 UI 인풋 참조
   - 메인 안내 문구 “본인 확인을 위해 비밀번호를 입력해 주세요”
   - 서브 안내 문구 “회원 탈퇴를 위해 현재 사용 중인 비밀번호를 입력해 주세요”
   - placeholder “비밀번호를 작성해 주세요”
2. CTA 버튼을 눌러 탈퇴 확인 모달을 띄운다
   - CTA 버튼 문구 “회원 탈퇴”
3. 탈퇴 요청에 실패하면(비밀번호 불일치 등) 비밀번호 인풋 테두리에 error 색상이 추가 되고 상단에 에러 토스트를 보여준다
   - 실패 토스트 문구 “5회 중 {n}번을 실패 하셨습니다. 인증번호를 확인해 주세요” ({n}은 실패한 횟수)

# 회원 탈퇴-소셜 계정

1. 회원가입/비밀번호 찾기/비밀번호 변경-공통의 이메일 인증 단계를 따른다(auth.md 참조). 다른 점은 아래와 같다
2. 이메일 인풋은 로그인한 계정 이메일로 고정되어 수정할 수 없다
   - 진입만으로는 인증 메일을 보내지 않고, CTA 버튼을 눌러야 보낸다
   - 서브 안내 문구 “이메일로 인증 번호를 발송해 주세요”
3. 이메일 인증 번호 인풋
   - 메인 안내 문구 “이메일로 인증번호를 발송 했습니다”
   - 서브 안내 문구 “회원 탈퇴를 위해 메일로 전송 된 인증번호를 작성해 주세요”
   - placeholder “인증번호 6자리를 작성해 주세요”
4. 인증에 성공하면 탈퇴 확인 모달을 띄운다
5. 탈퇴 요청에 실패하면 공통 UI 에러 페이지(404)로 넘어간다
