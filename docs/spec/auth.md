# 로그인

1. 공통 UI 인풋 참조
2. 상단의 화살표 아이콘을 눌러 이전 페이지로 넘어갈 수 있다
3. 이메일 인풋을 통해 이메일을 작성할 수 있다
4. 비밀번호 인풋을 통해 비밀번호를 작성할 수 있다
5. 로그인 버튼을 눌러 로그인 요청을 보낼 수 있다
   - 요청에 실패할 경우 이메일 인풋 테두리에 error 색상이 추가 되고 상단에 에러 토스트를 보여준다
   - 에러 메세지 “이메일 주소 또는 비밀번호를 확인한 후 다시 시도해 주세요”
6. google oauth 버튼을 눌러 oauth 로그인을 시도할 수 있다
7. 비밀번호 찾기 버튼을 눌러 url(”/password/find”)로 넘어간다
8. 회원가입 하기 버튼을 눌러 url(”/signup”)으로 넘어갈 수 있다
9. “로그인 시 쇼모아의 개인정보 처리방침과 위치정보 서비스 이용약관에 동의한 것으로 간주 합니다” 라는 문구를 사용자에게 안내하고 있다

# 회원가입

1. 공통 UI 앱바 참조
2. 메인 안내 문구 “이용 약관에 동의 해주세요”
3. 서브 안내 문구 “개인 정보 처리 방침과 위치 정보 서비스 약관을 확인해 주세요”
4. 개인정보 처리방침 체크 박스를 누를 수 있다
5. 개인정보 처리방침의 자세히 보기 버튼을 눌러 개인정보 처리방침 드로워를 꺼낼 수 있다
   - 개인 정보 처리 방침 드로워 공통 UI 앱바 참조
   - 사용자는 개인 정보 처리 방침을 스크롤을 하며 읽을 수 있다
6. 위치 정보 서비스 이용약관의 체크 박스를 누를 수 있다
7. 위치 정보 서비스 이용약관의 자세히 보기 버튼을 눌러 위치 정보 서비스 이용약관 드로워를 꺼낼 수 있다
   - 위치 정보 서비스 이용 약관 드로워 공통 UI 앱바 참조
   - 위치 정보 서비스 이용 약관을 스크롤을 하며 읽을 수 있다
8. 비밀번호 설정 인풋을 작성할 수 있다
   - 메인 안내 문구 “비밀번호를 설정해 주세요”
   - 서브 안내 문구 “안전한 비밀번호를 설정해 주세요”
   - placeholder “영문, 숫자를 포함한 8자 이상을 작성 하세요”
   - 검증 실패 문구 “영문, 숫자를 조합한 8자 이상으로 작성해 주세요”
   - 공통 UI CTA 버튼 참조
9. 비밀번호 확인 인풋을 작성할 수 있다
   - 메인 안내 문구 “비밀번호를 확인해 주세요”
   - 서브 안내 문구 “설정한 비밀번호를 확인해 주세요”
   - placeholder “비밀버호를 확인해 주세요”
   - 검증 실패 문구 “비밀 번호와 일치하지 않습니다. 비밀번호를 확인해 주세요”
   - 공통 UI CTA 버튼 참조
   - 가입 요청 시 이미 가입된 이메일일 경우 상단에 에러 토스트를 보여준다
   - 이미 가입된 이메일 토스트 문구 “이미 가입된 이메일이에요. 로그인해 주세요”
   - 가입 요청 시 이메일 인증이 만료됐을 경우 상단에 에러 토스트를 보여주고 이메일 인증 단계로 돌아간다
   - 인증 만료 토스트 문구 “인증 시간이 만료 됐어요. 이메일 인증을 다시 해 주세요”
   - 그 밖의 이유로 가입 요청에 실패할 경우 상단에 에러 토스트를 보여준다
   - 가입 실패 토스트 문구 “가입에 실패했어요. 잠시 후 다시 시도해 주세요”
10. 회원 가입을 완료할 경우 가입 완료 UI를 보여주며 하단 CTA 버튼을 눌러 바로 로그인 하고 url(”/”)로 넘어갈 수 있다
   - 상단 화살표 아이콘을 눌러 이전 페이지로 넘어간다
   - 메인 문구 ”가입이 완료 됐어요”
   - 서브 문구 “이제 보고 싶은 공연을 저장하고<br/>공연 정보를 한 눈에 확인해보세요”
   - 공통 UI CTA버튼 참조
   - CTA 버튼을 눌러 자동으로 로그인하고 url(”/”)로 이동한다

# 회원가입/비밀번호 찾기/비밀번호 변경-공통

- 단계(약관 동의·이메일 인증·비밀번호 설정 등)는 히스토리에 쌓지 않는다. 어느 단계에서든 앱바 화살표나 브라우저 뒤로 가기를 누르면 이전 단계가 아니라 이전 페이지로 넘어간다

1. 공통 UI 인풋 참조
2. 이메일 인풋을 작성할 수 있다.
   - 메인 안내 문구 “이메일을 인증해 주세요”
   - 서브 안내 문구 “메일을 입력하면 인증 번호가 발송 돼요”
   - placeholder “이메일을 입력해 주세요”
   - 검증 실패 문구 “이메일 형식을 확인해 주세요”
   - 요청 실패 토스트 문구 “유효하지 않은 이메일 입니다”
   - 회원가입에서 이미 가입된 이메일일 경우 인증 메일을 보내지 않고 인증 번호 단계로 넘어가지 않는다. 이메일 인풋 테두리에 error 색상이 추가 되고 상단에 에러 토스트를 보여주며, 작성한 이메일은 그대로 유지된다
   - 이미 가입된 이메일 토스트 문구 “이미 가입된 이메일이에요. 로그인해 주세요”
   - 인증 메일 발송이 제한된 경우(발송 후 60초 이내 재발송 등) 이메일 인풋 테두리는 그대로 두고 상단에 에러 토스트만 보여준다. 인증 번호 재발송 시에도 같다
   - 발송 제한 토스트 문구 “잠시 후 다시 시도해 주세요”
   - 비밀번호 변경은 이메일 인풋이 로그인한 계정 이메일로 고정되어 수정할 수 없고, 진입하자마자 인증 메일을 자동으로 발송해 인증 번호 단계로 넘어간다. 자동 발송에 실패하면 이메일 단계에 남아 상단에 에러 토스트를 보여주며, CTA 버튼으로 다시 발송할 수 있다
   - 공통 UI CTA 버튼 참조
3. 이메일 인증 번호 인풋을 작성할 수 있다
   - 메인 안내 문구 “인증 번호를 작성해 주세요”
   - 서브 안내 문구 “전송 된 메일을 확인하고 번호를 작성해 주세요”
   - placeholder “인증 번호 6자리를 작성해 주세요”
   - 검증 실패 문구 “숫자 6자리를 작성해 주세요”
   - 요청 실패 토스트 문구 “유효하지 않은 인증 번호 입니다”
   - 공통 UI CTA 버튼 참조
   - 공통 UI 타이머 참조
4. 비밀번호 설정 인풋을 작성할 수 있다
   - 메인 안내 문구 “비밀번호를 설정해 주세요”
   - 서브 안내 문구 “안전한 비밀번호를 설정해 주세요”
   - placeholder “영문, 숫자를 포함한 8자 이상을 작성 하세요”
   - 검증 실패 문구 “영문, 숫자를 조합한 8자 이상으로 작성해 주세요”
   - 공통 UI CTA 버튼 참조
